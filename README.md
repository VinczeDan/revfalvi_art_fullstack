# Revfalvi Art – Full Stack Web Application

## About

Revfalvi Art is a full-stack web application built for managing and showcasing artwork. The project consists of a React frontend and a Django REST backend.

---

## Technologies

### Frontend
- React
- HTML5
- CSS3

### Backend
- Django
- Django REST Framework
- PostgreSQL
---

## Features

- User-friendly interface
- REST API
- Responsive design
- CRUD operations
- Frontend and backend separation
- Email sending functionality 
- Admin panel
